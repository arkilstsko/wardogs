# Original trading-house emblems

Created 2026-10-26 as editable SVG geometry for this project. No external icon paths, recognizable corporate emblems, letter monograms, fonts or text-as-geometry are used. SVG title/description metadata provides accessible descriptions. Palette: ink `#11171B`, brass `#C5A56A`, ivory `#F4EBDD`.

Five original concepts: Meridian compass/route; Northstar port beacon; Vesper exchange/hourglass; Atlas linked structural arches; Redwood tree/warehouse. Each has a 64-viewBox master and a 24-viewBox scaled asset; 24px optical readability still needs browser/visual approval. All10 SVG files parsed as XML when authored. `SHA256SUMS` records exact source hashes.

Status: authored source assets, **unapproved** for final identity/commercial release. Geometry authorship is recorded; trademark/similarity and owner/art-direction review remain open. No external license grant or exclusive copyright assurance is claimed. Main UI integration was intentionally left unchanged; optional wrapper: `packages/ui/src/CompanyMark.tsx`.
